
# Assignment 5 - JavaScript Basics

This project contains tasks about JavaScript, DOM manipulation, and events.

## Pages

- index.html - Introduction to JavaScript
- dom.html - DOM Manipulation
- events.html - Mouse Events, Keyboard Events, and Calculator
- todo.html - Interactive To-Do List

## Technologies

- HTML
- CSS
- JavaScript

## How to Run

1. Download or clone the repository.
2. Open index.html in a browser.
3. Use the navigation bar to open different pages.

## Features

- Variables and operators
- Changing HTML content and styles
- Adding and removing list items
- Mouse and keyboard events
- Basic calculator
- Interactive To-Do List
